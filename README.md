# LuxeVista Resort 🏨
Android Hotel Booking Mobile Application

## About
A native Android mobile application for hotel room booking
and reservation management with Material Design UI.

## Features
- Room reservation & booking system
- Full CRUD operations
- SQLite local database
- Material Design UI
- Multi-layered form validation

## Technologies Used
- Android Studio
- Java
- SQLite Database
- Material Design UI
